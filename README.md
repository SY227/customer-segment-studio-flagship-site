# Customer Segment Studio Flagship Site v0.3.3

A source-grounded commercial website for the current Customer Segment Studio product.

## Core positioning

**Segmentation made simple. Strategy made visible.**

Turn customer data into an interactive strategy map that shows who matters, what to do next, and where your time and money can create the most value.

## v0.3.3 experience refinement

The website is deliberately shorter and more product-led:

1. Hero — what the product is and one clear live-product CTA.
2. Product Experience — one three-tab product showcase: **See the field → Understand the group → Make the move**.
3. Business Value — grow revenue and spend attention/discounting more deliberately.
4. How It Works + Trust — RFM flow, all nine groups, and methodology available on demand.
5. Final CTA — one natural close back into the live studio.

The product screenshots are real captures from the supplied Customer Segment Studio walkthrough. The commercial site does not embed the live app, video, or backend source.

## Run locally

```bash
npm run check
npm test
npm run build
npm run dev
```

Open `http://localhost:3000`.

If port 3000 is in use:

```bash
PORT=3001 npm run dev
```

## No API key required

The website is static. Gemini is part of the optional guidance path in the current flagship application, not this marketing site.
